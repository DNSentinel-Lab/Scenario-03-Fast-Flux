# 🛡️ Scenario 03 IR — SPL Validation

The IR search package is intentionally compact: it preserves the defender-side searches Sonia used to **independently** strengthen the SOC handoff.

```text
Validate data sources
→ rebuild historical DNS answers
→ establish answer chronology
→ correlate victim network activity
→ check current DNS/network activity
→ preserve one-client scope
→ support the response decision
```
