# 🔎 Scenario 03 — 5W1H Investigation Record

## 📌 WHO
- SOC Analyst / Threat Hunter: Abdul-Rehman
- Affected resolver-visible client: `10.50.30.20` / `dns-soc-victim01`
- Resolver: `10.50.30.10` / `dns-soc-resolver01`
- Other internal clients observed in reviewed scope: none
- Responsible user/process: unknown from available evidence

## 📌 WHAT
- Alert: `Suspicious Fast Flux DNS Behavior`
- Severity: Medium
- Domain: `flux.soclab.abdul4rehman215.tech`
- Repeated successful A-record DNS activity observed
- 274 A-query DNS events during 12:40–13:00 UTC
- Alert identified three matched public IPs: `13.220.94.188`, `52.73.218.100`, `54.81.98.44`
- Independent VPC Flow evidence confirmed allowed TCP/80 connections to all three
- Domain absent from configured benign Fast Flux lookup
- Behavior supports Fast Flux-like DNS/network activity but not malicious attribution

## 📌 WHEN
- Reviewed DNS activity first seen: ~12:40:12 UTC
- First flow to `13.220.94.188`: 12:45:26 UTC
- First flow to `52.73.218.100`: 12:47:08 UTC
- First flow to `54.81.98.44`: 12:48:57 UTC
- Production alert event time: 12:50:00 UTC
- DNS activity continued through ~12:59:59 UTC
- AI triage observed around 12:55:15 and 13:00:15 UTC

## 📌 WHERE
- Client: `dns-soc-victim01` / `10.50.30.20`
- Resolver: `dns-soc-resolver01` / `10.50.30.10`
- Domain: `flux.soclab.abdul4rehman215.tech`
- Destinations: `13.220.94.188:80`, `52.73.218.100:80`, `54.81.98.44:80`
- VPC Flow action: allowed
- Environment: DNSentinel AWS lab

## 📌 WHY
- Scenario domain generated 274 A queries, substantially above other client DNS activity.
- Alert correlated the domain to three public IPs and repeated connections.
- VPC Flow independently confirmed connections to all three.
- Domain was not in the known-benign tuning lookup.
- No endpoint/process evidence, user attribution, or proof of malware/ownership/intent was available.

## 📌 HOW
`dns-soc-victim01` repeatedly issued A queries for the scenario domain through the defender resolver. During the same investigation period the client established allowed TCP/80 flows to three public destinations identified by the production detection. The analyst validated DNS activity, network correlation, scope, baseline deviation, benign lookup status, and then validated AI advisory output before assigning disposition.
